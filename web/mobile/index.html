Installation och offline

iPhone och iPad: öppna den här sidan i Safari. Välj Dela → Lägg till på hemskärmen → Lägg till. Öppna sedan appen från hemskärmen och ange din webbnyckel där.

Android: tryck Installera högst upp, eller välj Installera app / Lägg till på startskärmen i webbläsarens meny.

Förbereder appen för offlineanvändning…

Punkter sparas även utan internet. Synkning körs vid start och när anslutningen återkommer medan appen är öppen. Sparade fältmanus fungerar offline; bakgrundskartan behöver normalt internet.

Låt appen vara öppen för aktuella GPS-positioner. Synka eller exportera punkter innan du rensar webbplatsdata. Punkter från den tidigare Android-appen synkas därifrån och blir kvar i webbbiblioteket; de flyttas inte automatiskt till den här telefonlistan.
